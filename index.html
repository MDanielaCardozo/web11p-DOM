Introducción al DOM de Javascript

El DOM es una representación del HTML como objetos en JavaScript. Nos permite modificar elementos en la página mientras se ejecuta.

🔍 Selección de elementos

Métodos del objeto document, para seleccionar elementos del html usando javascript

  • getElementById('id') → Selecciona por ID.
  • getElementsByClassName('clase') → Selecciona por clase.
  • getElementsByTagName('tag') → Devuelve por tipo de etiqueta.
  • querySelector(selector) Devuelve por tipo de etiqueta. → Devuelve el primer elemento que coincide.
  • querySelectorAll('selector') → Devuelve todos los que coinciden.

✏️ Modificar contenido:

  • textContent agrega texto plano (más seguro)
  • innerHTML interpreta HTML (⚠️ vulnerable a XSS si no se controla)

🎨 Manipular clases con classList:

classList es una propiedad de los elementos DOM que permite trabajar fácilmente con las clases CSS. Devuelve un objeto con métodos útiles.

Método Descripción
element.classList.add("clase") 🟢 Añade una clase si no está presente.
element.classList.remove("clase") 🔴 Elimina una clase si está presente.
element.classList.toggle("clase") 🔁 Alterna una clase: si está, la quita; si no está, la agrega.
element.classList.contains("clase") 🔍 Devuelve true si el elemento tiene la clase.
element.classList.replace("vieja", "nueva") 🔄 Reemplaza una clase existente por otra.
